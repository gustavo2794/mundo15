# **App Name**: Quinceañera Hub

## Core Features:

- Social Login: Allow users to register and log in using their Google or Facebook accounts.
- Academy Catalog: Display a catalog of academies with their name, photo, and costs.
- Academy Profile Pages: Dedicated page for each academy with detailed information.
- AI-Powered Academy Finder Tool: Enable searching for the relevant academies based on dance styles, pricing, location, and popularity. An AI LLM will determine when some specific style requests are implicit (e.g. `modern` might return tango, which while old-fashioned can be presented in a new and updated way).
- Contact Info: Clear contact details for the dance academies.
- Image gallery: Present photos or videos of each of the dance academy

## Style Guidelines:

- Primary color: Vibrant magenta (#E0007A) to represent the energy and excitement of a quinceañera.
- Background color: Light pink (#F8BBD0) for a soft and elegant backdrop.
- Accent color: Teal (#008080) for interactive elements and highlights, complementing the magenta.
- Body font: 'PT Sans', a modern and readable sans-serif for general text.
- Headline font: 'Playfair', an elegant serif font for headings and titles, conveying sophistication.
- Use elegant and playful icons related to dance, celebrations, and academies.
- Subtle animations for page transitions and loading states, adding a touch of dynamism.
